# Кривые разгона и подключения источников

В Results добавлены кривые «до» и «после» на общих шкалах:

- скорость скачивания по времени;
- подключённые сиды (сплошная линия) и все подключённые пиры (пунктир).

Для свежего официального тестового торрента отсчёт начинается перед отправкой запроса добавления в qBittorrent. Первые доступные показания сохраняются при подтверждении добавления, затем примерно раз в секунду во время ожидания трафика, 10-секундного прогрева и основного 60-секундного замера. Ненаблюдаемый участок не заполняется вымышленными нулями.

Показываются первое наблюдение трафика, первое наблюдение подключённого сида, время до 50% и до 90% опорной скорости. Опорная скорость — медиана скорости тестового торрента за последние 30 отсчётов основного замера. Достижение порога требует трёх последовательных отсчётов с интервалом около секунды: одиночный всплеск не считается устойчивым разгоном.

Данные о пирах — фактические подключения из статистики qBittorrent, а не число всех доступных источников в интернете. Если API не вернул численность подключений, она остаётся неизвестной. Для нового тестового образа кривые используют только этот торрент; прежние средние скорости всей сессии сохранены отдельно.

При ручном замере уже работающих торрентов отсчёт идёт от начала наблюдения. Интерфейс сообщает, что первоначальный запуск не наблюдался. Сравнение разгона новых образов и повторных запусков не доказывает причинность: состав раздающих меняется, а qBittorrent может помнить найденные адреса.

История и рассчитанные метрики сохраняются в JSON эксперимента. Локальные значения монотонного таймера не сохраняются в идентификаторе торрента, чтобы следующий запуск приложения не принял их за новое время старта. Старые результаты без новой истории продолжают открываться, но кривые для них недоступны.

Проверка: полный набор **98 тестов прошёл**; после последней правки сообщений повторены **42 затронутых теста**. Проверены известные кривые, одиночный всплеск, дубли быстрых показаний, отсутствие данных о пирах, изоляция постороннего трафика, сохранение данных и отрисовка двух графиков.

Настройки пользовательского qBittorrent и реальные загрузки во время проверки не изменялись.
