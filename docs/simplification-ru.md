**Упрощение архитектуры, версия 0.3.4 — 5 октября 2026**

Исходная работающая версия сохранена в GitHub, ветка `windows`, коммит `f3385f0`. Её дерево файлов точно совпадает с локальным снимком `122dd0f`. Исходный локальный коммит сохранён в ветке `codex/working-snapshot-122dd0f`. Основная ветка `main` не изменялась.

Выполнено:

- Удалены неиспользуемые BenchmarkManager, SessionManager, старое окно выбора среды и два диагностических скрипта: 427 строк устаревшего Python-кода.
- Удалена прямая зависимость matplotlib и восемь транзитивных пакетов из uv.lock. Из EXE исключены необязательные matplotlib/numpy, которые Pillow мог обнаружить в окружении сборки.
- Интернет-тест использует существующую очередь задач MainWindow. Одновременно запустить интернет-тест и замер торрента теперь нельзя в обоих направлениях. Кнопка теста отключается на время любой фоновой операции; закрытие окна ждёт завершения операции.
- Общая функция карточек перенесена в ui.tabs. Экраны больше не зависят от BenchmarkTab ради оформления.
- RAM определяется через уже установленный psutil. При ошибке сохраняется ручной выбор. Определение гибридных CPU и дисков осталось прежним.
- Лимиты скорости модели переименованы в *_kib_s: единицы теперь видны в имени, численные формулы и значения API сохранены.
- Скрипт версии использует tomllib и меняет только version в секции project, сохраняя остальной TOML. Тест версии окна сравнивает её с pyproject.toml.
- Run.bat использует постоянный путь outputs/qFrey-Tuner.exe. build.bat копирует в него EXE именно той версии, которая задана в pyproject.toml; старые versioned-сборки больше не имеют приоритета запуска.
- Сообщения различают резервную копию и подтверждённое применение. При неудачном восстановлении статус verified сбрасывается до записи; прежние значения остаются в резервной копии.
- Сравнение после отмены подписано как сохранённый эксперимент. Сообщения о слишком маленькой загрузке больше не называют любой тест Ubuntu.
- Сохранены параллельно добавленные отчёт о поведении qBittorrent, его тесты и показатели состояний торрента.

Проверки после повторного финального обзора: **110 тестов прошли**. Автоматические проверки GUI охватывают переходы между страницами, пустую страницу после навигации, графики, размеры кнопок при масштабировании 100–200%, взаимную блокировку измерений, статусы ошибки и исторические результаты. Дополнительно проверены сбой записи резервной копии до изменения настроек, частичный сбой восстановления и сохранение входов при сетевой ошибке. Отдельная проверка запуска настоящего окна прошла. Сборка PyInstaller, проверка зависимостей и запуск окна EXE завершились успешно; код завершения 0. Проверка содержимого архива подтвердила отсутствие numpy и matplotlib.

Живые настройки qBittorrent, личные торренты и скачанные ISO в ходе этой работы не изменялись. Новый сетевой эксперимент со скачиванием образа не выполнялся.

Атомарные резервные копии, проверки схемы/версии API, проверка применения чтением, ограничения удаления по адресу/хешу/тегу и отказ от недействительных замеров сохранены. Общий порог скорости для дополнительного сравнения T50/T90 и дальнейшее разделение MainWindow оставлены на будущую потребность; текущие метрики разгона сохранены.
